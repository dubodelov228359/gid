# Гид — туристический помощник

Сайт (он же приложение): **https://dubodelov228359.github.io/gid/**

- **Android:** APK-оболочка из `android/`. Само приложение она берёт с сайта, поэтому обновления
  приходят без переустановки. Без интернета работает последняя скачанная версия.
- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран Домой».

## Что умеет
Поездки в город, по маршруту или по стране; карта с отметками «были»; «Что рядом»; план по дням
с учётом выходных и билетов; гиды по местам с чтением вслух; автоотметка мест; офлайн-карты;
ИИ (Gemini бесплатно или Claude) по желанию.

## Устройство
- `docs/` — веб-приложение (GitHub Pages раздаёт эту папку)
  - `js/app.js` — экраны и навигация
  - `js/planner.js` — план по дням без ИИ
  - `js/places.js` — подборка Будапешта, OpenStreetMap, Википедия
  - `js/ai.js` — Gemini / Claude: места, план, маршрут по стране, гиды
  - `js/map.js` — карта MapLibre + OpenFreeMap с офлайн-кэшем
  - `js/platform.js` — геолокация, навигация, напоминания, озвучка, автоотметка
- `android/` — оболочка: WebView, разрешения, уведомления, фоновая автоотметка, озвучка

## Выпуск обновления
```
./publish.sh   # новая версия в docs/version.json
git commit -am "..." && git push
```
Через минуту-две GitHub Pages обновит сайт, приложение подхватит его при следующем запуске.

## Сборка APK
```
cd android && ./gradlew assembleRelease
```
Нужен ключ подписи `android/keystore/tripguide.jks` — **он не хранится в репозитории** (лежит у владельца).
С тем же ключом новые APK ставятся поверх старых без потери данных.
